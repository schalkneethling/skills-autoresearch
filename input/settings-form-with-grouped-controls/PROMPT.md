# settings-form-with-grouped-controls

Create the HTML for an account settings page. It has sections for: 'Profile' (display name text input, bio textarea, avatar upload), 'Notifications' (email notifications toggle, push notifications toggle, notification frequency radio buttons: Instant/Daily Digest/Weekly Digest), 'Privacy' (profile visibility radio: Public/Friends Only/Private, checkboxes for 'Show online status' and 'Allow search engines to index my profile'), and a 'Danger Zone' section with a 'Delete Account' button that is visually distinct. Each section should be clearly grouped. Include a 'Save Changes' button at the bottom.

Write the resulting HTML to `output/index.html` (or another file named in your task).
