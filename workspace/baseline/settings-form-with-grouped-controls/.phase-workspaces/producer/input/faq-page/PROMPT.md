# faq-page

Create the HTML for a FAQ page for a SaaS product called 'FlowBoard'. The page should have: a page header with breadcrumb navigation (Home > Support > FAQ), a search/filter input to narrow down questions, 3 FAQ categories ('Getting Started', 'Billing & Plans', 'Integrations') each with 3-4 questions, and a 'Still need help?' section at the bottom with a link to contact support and a phone number. Questions should be expandable. Use realistic questions and short but helpful answers.

Write the resulting HTML to `output/index.html` (or another file named in your task).
