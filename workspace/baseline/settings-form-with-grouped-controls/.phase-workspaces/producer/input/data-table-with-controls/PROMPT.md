# data-table-with-controls

Create an HTML page showing employee data in a table. The table has columns: Name, Department, Role, Start Date, and Status (Active/On Leave/Departed). Above the table there's a toolbar with: a search input, a dropdown to filter by department, a dropdown to filter by status, and a 'Download CSV' button. The table should have 8 rows of realistic employee data. Below the table, show 'Showing 8 of 42 employees' and pagination controls (Previous, page numbers 1-5, Next). Include a caption that describes the table.

Write the resulting HTML to `output/index.html` (or another file named in your task).
