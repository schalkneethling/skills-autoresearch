# dashboard-sidebar-nav

Create the HTML for a dashboard layout. It has: a fixed sidebar with the app logo, a primary navigation (Dashboard, Projects, Team, Reports, Settings — where 'Projects' is the current page), a secondary navigation section at the bottom of the sidebar ('Help & Support', 'What's New', user avatar with name 'Alex Chen' and a dropdown menu with Profile, Preferences, Sign Out). The main content area has a page heading 'Projects', a description paragraph, and 3 project cards each with a project name, status badge (Active/Paused/Complete), last updated date, and member count. Don't write any CSS — just the HTML structure.

Write the resulting HTML to `output/index.html` (or another file named in your task).
