# multi-step-form

Create the HTML for a multi-step checkout form for an online store. Step 1: Shipping information (full name, email, phone, street address, city, postal code, country dropdown). Step 2: Payment method (credit card with card number, expiry, CVV — just the fields, no actual processing). Step 3: Order review showing a summary of 2 items with quantities and a total. Each step should be clearly delineated. Include a progress indicator showing which step the user is on. Include proper error message markup for when a field is invalid, demonstrated on the email field.

Write the resulting HTML to `output/index.html` (or another file named in your task).
