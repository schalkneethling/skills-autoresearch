# pricing-comparison-table

Create the HTML for a pricing page with 3 plan tiers: 'Starter' ($9/mo), 'Professional' ($29/mo), and 'Enterprise' (custom pricing). Show a comparison table of features across plans. Features: 'Projects' (5 / Unlimited / Unlimited), 'Storage' (10GB / 100GB / Unlimited), 'Team members' (1 / 10 / Unlimited), 'API access' (No / Yes / Yes), 'Priority support' (No / No / Yes), 'Custom integrations' (No / No / Yes). Each plan also has a CTA button ('Start Free Trial' for first two, 'Contact Sales' for Enterprise). The Professional plan should be highlighted as 'Most Popular'. Include a heading and a brief intro paragraph.

Write the resulting HTML to `output/index.html` (or another file named in your task).
